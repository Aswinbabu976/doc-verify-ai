# Scenario: Reviewer checks an application

Martin opens Lina's application from the review queue. He sees each original document beside the extracted fields and verification report. The report flags a possible name mismatch and cites the rule used for the check.

Martin compares the documents, corrects one field that was extracted incorrectly, and requests a clearer copy of the unreadable page. After reviewing the updated evidence, Martin records the final decision and a justification. The AI recommendation and Martin's decision remain visible as separate records.
