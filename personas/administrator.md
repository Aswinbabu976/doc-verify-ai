# Persona: Sofia Brandt - Administrator

![Illustration of Sofia, a fictional administrator](images/avatar%203.jpg)

**Profile:** Sofia manages user access and verification rules for the admissions team.

**Profile:** Sofia manages user access and verification rules for the admissions team. She is confident with web tools and spreadsheets but does not write code.

## Goals

- Give each user the correct system role.
- Keep document types and verification rules up to date.
- Trace which rules were used for a verification.
- Review activity and system usage.

## Frustrations

- Users may have more access than they need.
- Rule versions and effective dates can be unclear.
- Missing activity history makes decisions difficult to trace.
- Routine updates may require technical help.

## Technical skills

Comfortable with web-based administration tools and spreadsheets. Basic technical knowledge; no programming experience.

## Scenario

Sofia updates a language-certificate rule in the test knowledge base and records its version and effective date. She checks that the system uses the updated rule for new verifications and that previous reports still show the version used at the time.
